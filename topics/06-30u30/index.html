Ilya's 30 papers: the shared foundations of LLMs and robotics

The 30 foundational papers Ilya Sutskever reportedly recommended to John Carmack, one per day. Each has its own page with a summary, core maths, deep dive, robotics angle, self-check and a link to code you can run.

Companion repo: Ojhaharsh/30u30 (from-scratch implementations, notebooks, 5 exercises per paper) · README saved in sources/06-30u30-readme.md

How to use this module

  • One paper a day. Read the course page first (20 min), then the original paper, then run the repo's train_minimal.py and do its exercises.
  • The repo is licensed CC BY-NC-ND, so these pages don't copy it. They're written from the original papers and link to the repo for code and exercises.
  • Tick papers off below. Progress is saved in this browser only.

New to all this? Start here

These 30 papers are some of the most important ideas behind today's AI, and behind the robots that learn.

A "paper" is a write-up where scientists explain a new idea and test whether it works. Many of these papers are hard, so every day in this module begins with a Start here box written for someone around 13. You don't need any maths for it.

How to do one day

  1. Read the Start here box (5–10 minutes).
  2. Try the "Try it" activity, and play with the interactive demo on the page.
  3. Check your understanding with the Self-check questions near the bottom. Click a question to see the answer.
  4. Only if you're curious: read the "Going deeper" parts and look at the code.

Stuck on a word? Every Start-here box has a Words to know list.

Two tracks, one toolbox: these papers are the shared foundations of both today's LLMs and robot learning. Each day has a badge: LLM (mainly language models), Robotics (mainly perception and control) or LLM + Robotics. Every page also has a "Why it matters for robotics" box. Some links are direct (PPO, RLHF, ResNet), and some are honestly conceptual (complexodynamics, Kolmogorov complexity).

Before you start

  • Maths: matrix multiplication, gradients and the chain rule, softmax, log-probabilities. Module 02 Stage A covers them.
  • Setup: clone the repo, then for each day run pip install -r requirements.txt in that paper's folder. Most code is NumPy or PyTorch and CPU-friendly.
  • Habit: attempt each exercise before opening the solution (Module 03, don't automate your own learning).
