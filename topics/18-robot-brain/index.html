Build a Robot Brain: 16 weeks, from zero to a robot that understands you

You build your own robot, one piece a week. It moves, senses, reads real phone data, drives on wheels, draws a map, finds itself when lost, and understands "put the red block in the bin".

Zippy> put the red and blue blocks away
  (I think you meant: 'put the red and blue block away')
  (I thought for 0.34 ms, so I'd roll 0.34 mm meanwhile.)
  Something is in the way at (4, 1)! I stopped just in time (stop chance 0.99, my safe threshold 0.17).
  The red block is in the bin. The blue block is in the bin.

Real output from a finished my_robot.py (ours is called Zippy). The thinking time changes a little every run.

Start here

You learn by building. Every week you write a few real lines of Python, and your robot can do one new thing.

Every page uses the same coloured boxes, in this order:

  1. 💡 The idea with a picture, before any code.
  2. 🎮 Play with it in your browser.
  3. 🛠 Build the homework, one function at a time.
  4. ✅ Checkpoint after every step: the exact output you should see, and what to do if yours is different.
  5. 🆘 Stuck? hints, one at a time. The last one is fill-in-the-blanks.
  6. 🤖 Add it to your robot: fill this week's gap in my_robot.py.
  7. 🌍 Try it for real: your phone, a ramp, a friend.

You need: very basic Python (variables, if, for, functions). If you can print 1 to 10 with a loop, you're ready. A grown-up helps with setup in week 1.

Time: 16 weeks. Half the weeks have two parts (A and B). Each page says how long it takes. If a week takes two, that's normal.

What you'll learn

🦾 The robot's body

  • Sensors: noisy distances, real phone data, gyro drift and fusion (weeks 2, 3, 6)
  • Motion: grids, routes with A*, wheels and odometry (weeks 1, 5, 9)
  • Control: PID steering that doesn't overshoot (week 9)
  • Maps: a laser scan, its own map, and finding itself when lost (weeks 11, 12)

🧠 The robot's brain

  • Learning: shrinking the error, a neuron, honest tests (weeks 2, 4)
  • Language: words as numbers, commands, a tiny language model (weeks 7, 8)
  • AI engineering: safety checks, speed, cost, LoRA, Claude, a bake-off (weeks 10, 13–15)
  • People: learning what people prefer (week 16)

Getting the code

  1. The project is in topics/18-robot-brain/project/. Copy the whole project folder somewhere you like, and read its README.md.
  2. Your files are in project/homework/. Answers are in project/solutions/: peek only after a real try.
  3. Check a lesson from inside project/: python3 check.py 21 checks lesson21_phone.py (week 3). Each page names its file.
For parents and teachers
  • Shape: the course alternates the robot's body (sensors, motion, control, maps) and its brain (learning, language, AI engineering). Weeks 13–15 are inference engineering: how fast and expensive a brain is, making it cheaper, and racing every brain on the same tasks.
  • Real data: week 3 uses a real smartphone recording from the UCI "Human Activities and Postural Transitions" dataset (Reyes-Ortiz, Anguita, Oneto, Parra; CC BY 4.0). Learners can record their own with the free phyphox app. Please help them install it.
  • Installs and the API key: weeks 1–14 need only Python (standard library). Week 15 and the MCP bonus install one package each with pip; an adult should help. Week 15 can use Claude, which needs an API key and costs a little per request (the whole bake-off is about a dollar). Without a key, the Claude parts are skipped, and everything else works.
  • Self-marking: check.py gives specific hints. python3 check.py all --solutions verifies the reference solutions: all 147 checks pass. python3 progress.py shows what each finished lesson adds.
  • Honest by design: the week 10 capstone scores 83%, not 100%. The small brains reach 10/12 but never 12/12. Odometry drifts until weeks 11–12 fix it. Finding and explaining failures is part of the course.
  • Error bars: 12 tasks is few. 5/12 to 8/12 is "too close to call"; 5/12 to 10/12 is a real difference (week 15 shows how to tell).
  • More depth: the 30 papers, inference engineering, free robotics courses. Bonus after week 5: robot maths and steering with a field of arrows.
