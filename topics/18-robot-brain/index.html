LLM + RoboticsModule 18 · Our own course, for ages 12+

Build a Robot Brain: 12 weeks, from zero to a robot that understands you

You'll build Robo-Helper, a robot in a simulated room that understands "put the red block in the bin", plans a route, notices a cat in the way, and reports honestly how well it works. Every idea starts from first principles, and every lesson ends with real code you write and real-world practice away from the screen.

Start here

People don't learn by reading. They learn by building, getting stuck, and fixing it. So that's how this course works.

How every lesson goes

  1. A real problem. Something the robot can't do yet.
  2. First principles. We build the idea from nothing, with pen-and-paper examples.
  3. Play. A small interactive demo in your browser to poke at the idea.
  4. Homework. You write the real Python code, and check.py marks it.
  5. Real-world challenge. Try the idea on something real: your phone, a ramp, a friend.
  6. Add it to your robot. Fill this week's gap in your robot file, my_robot.py, then run it: it can do one new thing.

What you need to know already

Very basic Python: variables, if, for loops, and functions. If you can write a loop that prints 1 to 10, you're ready. Lesson 0 helps you set up.

Time

12 weeks. Most weeks are one lesson of 2–4 hours; weeks 2, 3, 5, 7, 9 and 12 have two lessons, so plan 4–7 hours (or take two weeks). Ages 12+ is fine: weeks 1–7 are the core, weeks 8–12 are harder, and an adult helps with setup in week 1 and the API key in week 10. Weeks 1–7 build the robot and its first brains from zero. Weeks 8–11 are inference engineering (inference means a brain answering, not learning): measuring how fast and expensive a brain is, making it faster and cheaper, plugging in a world-class model (Claude) over the internet, and racing every brain on the same tasks. Week 12 teaches the robot what people prefer, and you show off your work.

The 12 weeks

Follow the weeks, top to bottom; the Next button on every lesson does it for you. Lesson numbers are just names (Lesson 15 comes in week 6, because we added it later). Each lesson starts with a strip saying what your robot can do so far and what it learns today. Badges show which side of AI each lesson builds.

Week 1 · Moving

Set up, then make the robot move on a grid.

00

Install Python, run the robot world, write two tiny functions. Adds: your first robot script.

01

(x, y), directions as small changes, walls. Adds: the robot can move.

Week 2 · Sensing and learning

Noisy sensors, then the idea behind all AI: shrink the error.

02

Measuring distance, why sensors are never exact, why averaging helps. Adds: a distance sensor.

03

Error, then gradient descent: how every AI learns. Adds: learns its own braking distance.

Week 3 · Neurons and honest tests

One artificial neuron, and how to test it so it's safe.

04

Weights, a sum and a squash: the brick every neural network is built from. Adds: an obstacle detector.

05

Test on data the model never saw. Precision, recall, and choosing a safe threshold. Adds: tested stop decisions.

Week 4 · Planning

Find the shortest route with BFS and A*.

06

Breadth-first search, then A*. Adds: route planning.

Week 5 · Words

Turn words into numbers; understand commands.

08

Tokens and next-word prediction, the core idea behind ChatGPT, put straight to work fixing typos the way a phone keyboard does. Adds: typo-proof commands (typo commands handled right: 6/9 → 9/9).

09

A classifier that counts words, plus "slots" for which object. Adds: understands one action per command (5 of 12 on the bake-off, a test of 12 tasks you'll run in week 11).

Week 6 · A neural language model

Build a tiny LLM from zero.

15

Embeddings, softmax and next-word prediction in a real (tiny) neural network that writes whole plans word by word ("put red blue"), asks when you're vague, and learns from 343 examples you generate from templates (never from the bake-off's commands). Stretch: add attention, the idea inside Transformers. Adds: multi-step plans (bake-off 5 → 8/12).

Week 7 · Capstone

Safety checks on AI output, then the whole robot, tested.

10

Structured output, strict checks, and a fallback. Adds: a safety layer so AI output can't break the robot.

11

Put it all together and measure it honestly. Adds: the full robot.

Week 8 · Inference I: measure

Inference means a brain answering, not learning. This week: latency, tokens and cost.

16

Latency, p50 vs p95, time to first token, tokens per second, and cost per command. How far does the robot roll while it thinks? Adds: a time budget for every brain.

Week 9 · Inference II: speed up

Caching, quantising, distilling, and LoRA fine-tuning.

17

Caching, quantising weights to 8 and 4 bits, and distilling a teacher into a small student. Adds: a brain that learns new phrasings, then shrinks 8× (bake-off 10/12 in 1.4 KB).

13

Fine-tuning vs a tiny low-rank add-on: fix a big model by training a few numbers. Adds: adapts a factory model to your robot.

Week 10 · A world-class brain

Claude as planner and as agent, over the internet.

18

Claude as the robot's brain: a planner that writes a checked plan, and an agent that uses the robot's tools step by step. You stay in charge. Adds: world-class understanding.

Bonus after week 10 · MCP

Needs Python 3.11+ and one install (pip install mcp).

20

Turn the robot's tools into an MCP server that Claude Desktop, Claude Code and other apps can drive, with safety rules no AI can talk its way past. Adds: a real MCP server.

Week 11 · The bake-off

Every brain, scored and replayed.

19

Every brain, the same 12 tasks, the same cat. Score correctness, speed and cost, then watch the replays side by side. Stretch: use an AI model as the judge, catch it being fooled, and measure it honestly with kappa and error bars (Module 19). Adds: a scorecard showing your robot getting better: 5 → 8 → 10/12.

Week 12 · Teach it, show it

Learn from people's preferences; share your project.

12

Show two routes, ask which is better, learn a reward from the answers, pick what people like. The same recipe that trains chat assistants. Adds: picks the route you'd choose.

14

Show your work, then (optionally) put it on real hardware. Adds: a project you can show your teacher, your friends or a science fair.

Bonus, any time after week 4

07

Rewards and Q-learning: no map, just practice. Adds: learns a maze by itself.

Your robot, built by you: my_robot.py

From week 1 you have one robot, and you build it. It's a single file, homework/my_robot.py, with your robot's name at the top and one gap for each week. Every lesson ends with "Add it to your robot": you write the 5–20 lines that connect what you just learned to your robot. Week 1, the arrow keys. Week 3, checking for the cat before every step. Week 5, turning sentences into actions. Week 6, plugging in the language brain you wrote, and so on. Until a gap is filled, your robot politely says "I can't do that yet".

Only the boring parts are provided: drawing the room, the typing loop and the showcase. Everything that makes it clever is your code. python3 check.py robot drives your robot and checks each piece (1 of 12 after week 1, 12 of 12 at the end), and solutions/my_robot.py is there if you're really stuck.

The brain you build climbs the bake-off week by week, on the same 12 tasks it never trained on: word counter 5/12 (week 5), plan-writing tiny LM 8/12 (week 6), plus a teacher's labels 10/12 (week 9), and still 10/12 squeezed into 1.4 KB. The two tasks every small brain still fails need the robot to see the room ("the block that's closest to the bin") or to know that "the room" means every block. That's the job for Claude in week 10.

Honest caveat: 12 tasks is few. The jump from 5/12 to 8/12 is "too close to call" with error bars; 5/12 to 10/12 is a real difference (week 11 shows how to tell).

Bonus, any time after week 4: Module 22 steers the robot with a field of arrows (gradient, divergence, curl). Bonus: Module 21 pairs ten interactive maths explainers (Kalman, Bayes, A*, Fourier…) with bonus_robot_math.py, which uses each one on Robo-Helper and measures the difference.

Getting the code

  1. The project lives in topics/18-robot-brain/project/ inside this course folder. Copy that whole project folder somewhere you like.
  2. Read project/README.md.
  3. Your files are in project/homework/. Answers are in project/solutions/, but peek only after a real try.
  4. Check any lesson with python3 check.py 3 (from inside project/).

For parents and teachers

  • Installs: weeks 1–9 need only Python (standard library). Week 10 and the MCP bonus install one package each with pip, in a private folder; an adult should help. Weeks 10–11 can use a real world-class model (Claude), which needs an API key and costs a little per request (the whole bake-off is about a dollar). Without a key, students replay recorded real runs, so nothing is blocked.
  • Self-marking: check.py gives specific hints. python3 check.py all --solutions verifies the reference solutions (all 100 checks pass). python3 progress.py shows what each finished lesson added to the robot.
  • Honest by design: the finished robot scores 83% on its test set, not 100%, and the small brains it builds climb from 5/12 to 10/12 on the bake-off but never reach 12/12. Finding and explaining failures is part of the course.
  • Want more depth? Each lesson links to the matching part of this course: the 30 papers, inference engineering, free robotics courses.
